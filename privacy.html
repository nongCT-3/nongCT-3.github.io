Privacy Policy

Last updated: 13 November 2026

Who uses this app

Cyrus Secretary is a personal assistant used only by its developer, Ronnaphum Fueachai. It is not available to other users.

Data the app accesses

  • Google Calendar (calendar.events): to read, create, update and delete the owner's events and study sessions.
  • Gmail (gmail.readonly): to read the sender, subject and short preview of recent emails. The app cannot send, delete or modify emails.

How data is used and stored

  • Data is stored only on the owner's own computer or private server (local files and a local SQLite database).
  • To understand requests and write summaries, selected text (messages, event details, email subjects and previews) is sent to the Anthropic API. Banking emails, one-time passwords and verification codes are filtered out in code and are never sent.
  • Data is not sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Cyrus Secretary's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting data and revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local files removes all stored data.
